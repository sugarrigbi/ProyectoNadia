			configurar nginx:
				Nginx es un servidor web que actúa de portero entre internet y tus apps Flask
				Nginx recibe el tráfico en 80/443 y lo redirige a Flask.
				Para HTTPS necesitas certificados SSL y Flask no los maneja bien
				Si tienes múltiples apps no sabes a cuál mandar el tráfico				
				crear config:
					sudo nano /etc/nginx/conf.d/gaialink.conf
				crear lo q va en config:
					server {
						listen 80;
						server_name gaialink.online;

						location / {
							proxy_pass http://localhost:5009;
							proxy_set_header Host $host;
							proxy_set_header X-Real-IP $remote_addr;
						}

						location /api/ {
							rewrite ^/api/(.*) /$1 break;
							proxy_pass http://localhost:5000;
							proxy_set_header Host $host;
							proxy_set_header X-Real-IP $remote_addr;
						}
					}

					server {
						listen 80;
						server_name api.gaialink.online;

						location / {
							proxy_pass http://localhost:5000;
							proxy_set_header Host $host;
							proxy_set_header X-Real-IP $remote_addr;
						}
					}
				validar config:
					sudo nginx -t	
				relodaer nginx:
					sudo systemctl reload nginx
